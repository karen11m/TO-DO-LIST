# ✅ To-Do List App

**Desarrollado por: Karen Tatiana Mendez Bojaca

## 📱 Descripción
Aplicación móvil Android para gestionar tareas personales. Permite crear, editar, eliminar y marcar tareas como completadas con persistencia en SQLite.

## 🛠️ Tecnologías
- Java
- SQLite
- RecyclerView
- Material Design
- SQLiteOpenHelper

## ✨ Funcionalidades
- ✅ Crear tareas
- ✅ Leer lista de tareas
- ✅ Actualizar estado (completada/pendiente)
- ✅ Editar tareas
- ✅ Eliminar tareas
- ✅ Contador de tareas pendientes
- ✅ Fecha y hora de creación

## 🚀 Cómo ejecutar
1. Clonar este repositorio
2. Abrir en Android Studio
3. Sincronizar Gradle
4. Ejecutar en emulador o dispositivo físico
